# mi-web

Personal site of Mariano Lacerna, Senior VFX Compositor. One file, no build: `index.html`.

- Live: https://marianolaxerna-eng.github.io (GitHub Pages, branch `main`)
- Preview locally: open `index.html` in a browser.
- Edit colors in `:root` (`--accent` is the single accent color).
- Edit the showreel: the Vimeo `<iframe>` inside `#showreel`.
- Edit jobs: the `<ul class="timeline">` block inside `#career`.
- Publish: `git add -A && git commit -m "..." && git push origin main`
